# frontend-fundamentals

> Learning repository for frontend development fundamentals — HTML, CSS, page structure, forms, layouts, and introductory web interface construction, organized progressively through SENA formation and self-directed practice.

---

# Overview

This repository documents the learning journey through frontend development fundamentals.

The content is organized progressively:

* Each top-level folder represents a major frontend learning area.
* Topics are numbered according to the recommended study order.
* Exercises increase gradually in complexity.
* Practical activities reinforce each theoretical concept.

This repository is a **learning repository**, not a template.

Its purpose is to:

* Document frontend learning progress
* Store exercises and assessments
* Build a personal reference library
* Reinforce concepts learned during SENA formation
* Create a foundation for future frontend frameworks and application development

---

# Learning Objectives

By working through this repository, you will be able to:

* **Understand HTML fundamentals**

  * Semantic elements
  * Document structure
  * Accessibility-oriented markup
  * Content organization

* **Build page layouts**

  * Headers
  * Main content areas
  * Sections
  * Footers

* **Apply CSS fundamentals**

  * Selectors
  * Properties
  * Typography
  * Colors
  * Spacing
  * Positioning

* **Work with common HTML elements**

  * Paragraphs
  * Lists
  * Links
  * Images
  * Forms

* **Manage project assets**

  * Relative paths
  * Image organization
  * Resource references

* **Create complete static pages**

  * HTML structure
  * CSS styling
  * Basic responsive thinking

* **Develop frontend problem-solving skills**

  * Analyze requirements
  * Implement layouts
  * Improve visual organization
